## Overview
This repository contains the code for the **Sales Prediction using Python** project completed as part of the CodeAlpha Data Science Internship. The objective is to forecast future sales outcomes based on promotional and advertising expenditures using regression machine learning model.

## Project Workflow
1. **Dataset Loading:** Automatically fetched the sales transaction dataset using `kagglehub`.
2. **Data Transformation & Cleaning:** Handled missing values, filtered unnecessary index columns, and performed feature selection.
3. **Model Training:** Split data into training and testing subsets and trained a **Random Forest Regressor** to map advertising investments to expected sales returns.
4. **Model Evaluation:** Evaluated prediction accuracy using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and $R^2$ Score.
5. **Visualization:** Generated scatter plots to visually compare model predictions against actual sales figures.
